# Character Philosophy

Main protagonist changes every game.

Never create a "chosen one."

Instead:

Every story follows an ordinary person discovering something extraordinary.

Previous protagonists may return as:

- mentor
- villager
- old traveler
- legend
- memory

The world is the protagonist.

Not a single character.

---

# Mystery Design Philosophy

Mysteries should reward attention.

Never IQ.

Never randomness.

Players solve mysteries because they noticed something.

Not because the game suddenly reveals it.

---

# Choice Philosophy

Choices should mostly change meaning.

Not plot.

Example

```
Stay silent.

Speak.

Smile.
```

The destination stays.

The emotional journey changes.

---

# Exploration Philosophy

Exploration should reward curiosity.

Rewards include:

- hidden dialogue
- memories
- letters
- stories
- philosophy
- character moments

Not stronger weapons.

---

# RPG Philosophy

The final RPG is **not** about defeating enemies.

It is about living in Bellwood.

Examples of quests:

- Deliver a forgotten letter.
- Help repair a lighthouse.
- Find a place where silence still grows.
- Finish someone’s unfinished story.
- Return a borrowed book after twenty years.

Phronesis is the Greek word for practical wisdom.

Not wisdom about big things.

Wisdom about small ones.

Knowing which conversation matters today.

Knowing when to speak and when to water a garden instead.

Knowing that tending is not the same as fixing.

Game IV teaches it the only way it can be taught:

By letting the player practice it.

---

# Studio Philosophy

We don’t make games about reading.

We make games that make people love reading.

We don’t teach people how to live.

We quietly invite them to rediscover it.

The world has a doomscrolling problem.

Not because people are broken.

Because everything around them competes for the part of attention that stories used to hold.

This series is a quiet attempt to hand that part back.

Game by game.

Philosophy by philosophy.

Without announcing itself.

Readers should never finish a chapter feeling smarter.

They should finish feeling quieter.
